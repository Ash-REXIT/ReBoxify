# Re-Boxify: Smart Reusable Packaging Ecosystem 📦♻️

Re-Boxify is a high-fidelity circular logistics platform designed to eliminate single-use packaging friction for MNCs and consumers. By integrating mandatory deposit safeguards and real-time lifecycle tracking, we transform packaging from waste into a high-value ecological asset.

## 🌟 Key Features

### 🔐 Unified Control Hubs
- **Consumer Portal**: Track possession status, escrow deposits, and Green Token rewards.
- **Logistics Hub**: Rugged, mobile-optimized QR scanning workflows for delivery partners.
- **Enterprise MNC Dashboard**: Real-time fleet telemetry, ESG reporting, and brand-unique asset management.
- **Super Admin Security**: Platform-wide governance, global disruption registry, and partner orchestration.

### 🛡️ Accountability Protocol
- **Escrow Safeguards**: Automated deposit collection to ensure asset returns.
- **Lifecycle Telemetry**: Track "Cycles per Box" to optimize inventory replacement.
- **Disruption Registry**: Direct reporting of box degradation with real-time MNC triage.

### 🎨 Universal Design System
- **Premium Aesthetics**: Mesh gradients, glassmorphism, and smooth micro-animations.
- **Dual-Mode Fidelity**: Seamless transition between high-contrast Light and Dark modes.
- **Mobile First**: Fully responsive layouts optimized for logistics operations.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS (Class-based Dark Mode)
- **Navigation**: React Router 7
- **State Management**: LocalStorage Persistence (Simulated Ledger)
- **Scanning**: HTML5-QR-Code Library

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Explore Portals**:
   - Access the landing page and choose a role (Consumer, Partner, MNC, or Super Admin).
   - Use the 'Login' buttons in each role card to enter the respective dashboards.

## 📈 ESG Compliance
Re-Boxify aligns with **UN SDG 12 (Responsible Consumption and Production)** and **SDG 13 (Climate Action)** by automating the circular economy at scale.
